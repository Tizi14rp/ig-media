Posts para aprobar

Conectar con GitHub

Esta app usa tu cuenta de GitHub para aprobar (Merge) o rechazar los posts. Necesita un token de acceso que creás vos en GitHub y que queda guardado solo en este celular.

  1. Abrí GitHub → Fine-grained token.
  2. Nombre: App aprobar posts. Vencimiento: el que prefieras.
  3. Repository access: Only select repositories → ig-brain.
  4. Permissions: Contents → Read and write · Pull requests → Read and write.
  5. Generate token, copialo y pegalo acá abajo.

No compartas este token con nadie (tampoco en el chat). Si perdés el celular, borralo desde GitHub → Settings → Tokens.
